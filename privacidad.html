Política de privacidad de Clips Sebastián

Vigente desde el 18 de octubre de 2026.

Quién la usa

Clips Sebastián es una aplicación personal de Sebastián Pedroza Ruiz. La usa solo él, con su propia cuenta de Google, para administrar su propio canal de YouTube. No se ofrece a otras personas.

Qué datos usa y para qué

  • Su canal de YouTube: subir y programar sus videos, editar sus títulos y descripciones, y leer las estadísticas del canal.
  • Comentarios públicos de sus videos: leerlos para contestarlos o moderarlos desde el canal. Incluyen el nombre público y el texto que cada persona publicó en YouTube.

La aplicación accede a estos datos mediante las API de YouTube de Google, solo con el permiso que el dueño del canal otorga al iniciar sesión.

Dónde se guardan

El permiso de acceso (token) y los datos que se descargan se guardan únicamente en la computadora del dueño del canal. No se suben a servidores propios ni de terceros.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google se apegan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. También aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el permiso

El dueño del canal puede revocar el acceso en cualquier momento desde la página de permisos de su cuenta de Google. Al hacerlo, la aplicación deja de tener acceso y el token guardado en su computadora deja de funcionar.
